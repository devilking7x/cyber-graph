What this is — honestly

This page runs the real Relate engine v1.2.0 (Neo4j's embedded graph database, relatedb/relate, Apache-2.0), compiled to WebAssembly. Every query below executes as Cypher inside that engine — there is no fake graph layer and no hosted Neo4j/Aura instance. The graph is seeded from seed.cypher into an in-memory store when the page loads. The same seed is stored durably as a single-file Relate store at store/cybergraph.rl in the repo — open it with the Relate CLI or Python and inspect it.

Free solo build: no server, no account, no tracking, works offline once loaded. Nodes you add in the form below live only in this browser session; the committed store is unchanged.

Data & provenance

34 nodes, 39 relationships, hand-written for this project from public knowledge: 8 CVEs, 8 CWEs, 6 CAPEC attack patterns, 6 MITRE ATT&CK techniques, 6 products. Summaries are simplified and educational — verify any fact against NVD, CWE, CAPEC or MITRE ATT&CK before relying on it. The full seed is seed.cypher in the repo.

Relationships: Vulnerability —HAS_WEAKNESS→ Weakness, AttackPattern —EXPLOITS→ Weakness, Technique —USES→ AttackPattern, Technique —TARGETS→ Vulnerability, Vulnerability —AFFECTS→ Product.

Reproduce the store: pip install relate-db && python scripts/seed_store.py, then relate --database ./store/cybergraph.rl --read-only "MATCH (n) RETURN count(n)".
